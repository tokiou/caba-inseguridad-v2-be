# Add Project README

## Why

El repositorio no tiene un README raíz que explique su propósito, arquitectura,
decisiones de escalabilidad y forma de ejecución a una persona nueva en el
proyecto.

## What

Agregar un README en español con:

- resumen funcional y stack;
- arquitectura por capas y flujo de una request;
- razones por las que el diseño escala mejor que un backend acoplado;
- endpoints principales, configuración y comandos de desarrollo;
- límites actuales y enlaces a documentación más específica.

## Scope

Incluye únicamente documentación. No cambia código, contratos HTTP ni
configuración de ejecución.
